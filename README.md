# ALX Data Science Program Portfolio

A learning and practice portfolio from my data science training, covering Python, SQL, machine learning foundations, data validation, and notebook-based analysis.

This repository contains public learning material and practice notebooks. It is separate from employer, client, or NDA-protected work.

## Focus Areas

- Python for data analysis
- SQL querying and relational data exploration
- Exploratory data analysis
- Data validation and quality checks
- Regression modeling
- Classification workflows
- NLP and image classification practice
- Clustering and unsupervised learning
- Recommendation-system foundations
